# Semeko

A desktop IDE for C/C++, Python, Java and C#, upgraded from Sameko Dev C++.

## Download and install

**[Trang tải Semeko](https://graperu.github.io/semeko-pro-downloads/)** · **[Bản phát hành mới nhất](https://github.com/graperu/semeko-pro-downloads/releases/latest)**

1. Download `semeko-pro-setup-1.4.3-x64.exe` from the release assets.
2. Save your work and close Semeko, then run setup. It installs for your Windows account and creates **Semeko** shortcuts on the Desktop and Start Menu.
3. Open the app, select a language, and press Run.

Windows 10/11 64-bit. Allow about 6 GB free during installation for the SDKs and temporary extraction. The full installer includes GCC/GDB/clangd, Python, a Java JDK and .NET SDK for basic compile/run. Node.js and Git are not required. Third-party Python packages and optional language servers/debug adapters are separate. Internet is needed for online platforms and some project dependencies. Other .NET target frameworks may need additional SDK packs.

The installer is not code-signed; Windows may show a reputation prompt. Updates preserve your source files and settings.

## Cập nhật ứng dụng và tài liệu

App báo có phiên bản mới khi mở hoặc kiểm tra định kỳ. Trên Windows, bấm nút tải bản mới để mở trang phát hành chính thức, tải bộ cài và cài đè sau khi lưu bài/đóng app.

Tài liệu cập nhật riêng: **Cài đặt → Giới thiệu → Quản lý và cập nhật tài liệu**. Chọn **HackerRank**, bấm tải/cập nhật, sau đó mở lại app. Gói hiện có **1.069 đề Anh/Việt** thuộc sáu danh mục đã lập chỉ mục. Đọc các bản dịch đã tải không cần API key AI. Người đã tải trước đây chỉ cần cập nhật gói này.

Trang download hiển thị tổng lượt tải bộ cài Windows từ các bản chính thức và lượt tải bản mới nhất, lấy từ GitHub Releases. Đây là lượt tải tệp, không phải số người dùng riêng biệt; không cộng lượt tải checksum hoặc blockmap. Nếu API thống kê tạm lỗi, liên kết tải bộ cài vẫn hoạt động.

## Features

- Language workspaces and multi-file folders
- Codeforces, LeetCode and HackerRank practice browser
- Official read-only samples with per-test results
- Contest/Collections, Material icons, themes and split editor
